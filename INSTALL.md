# Install

This repository is the Home Assistant integration. Install it with HACS or by copying `custom_components/omarchy_themes` into `/config/custom_components/omarchy_themes`, then restart and add Omarchy Themes under Settings → Devices & services.

See [README.md](README.md) for the steps.

More dashboards and smart home kits: [topendsmarthomes.com.au](https://www.topendsmarthomes.com.au/?utm_source=omarchy-theme-builder&utm_medium=integration&utm_campaign=install).
