# Install

This repository is the Home Assistant integration. On Home Assistant **2026.11 or newer**, install it from **Settings › Marketplace** (Add from link). On **2026.10 or older**, install it with HACS. Or copy `custom_components/omarchy_themes` into `/config/custom_components/omarchy_themes`, then restart and add Omarchy Themes under Settings → Devices & services.

See [README.md](README.md) for the steps.

More dashboards and smart home kits: [topendsmarthomes.com.au](https://www.topendsmarthomes.com.au/?utm_source=omarchy-theme-builder&utm_medium=integration&utm_campaign=install).
